# 🚗 AvtoRent — Zamonaviy Avtomobil Ijarasi Platformasi (Car Rental Marketplace)

O‘zbekiston bo‘ylab zamonaviy avtomobil ijarasi (P2P Car Rental) platformasi. Uzum Market va Airbnb dizaynidan ilhomlangan, mobil va kompyuter uchun to‘liq moslashtirilgan (responsive).

---

## ✨ Asosiy Imkoniyatlar

- 📱 **Mobil & Notebook Responsive:** Telefonda 2 qatorli qulay cardlar (Uzum Market uslubi), pastki navigatsiya paneli (Bottom Navigation).
- 🚗 **Mashinalar Katalogi:** 8 ta mashina (Pinterest HD rasmlari, kunlik narxlar, shahar, xarakteristikalar).
- 🔍 **Filter & Qidiruv:** Marka, shahar/hudud, narx oralig‘i, kuzov turi, uzatma qutisi (avtomat/mexanika), yoqilg‘i turi.
- 📅 **Ijara Kalkulyatori:** Boshlanish va tugash sanalarini tanlash, kunlar hisobi, qaytariladigan depozit va jami summa hisob-kitobi.
- ➕ **Mashina Qo‘shish (8 bosqichli Wizard):** O‘z mashinangizni ijaraga berish, telefon/kompyuter papkasidan real rasm yuklash yoki Pinterest galereyasidan tanlash.
- 🔑 **Email OTP Autentifikatsiya:** Emailni kiritish, 6 xonali tasdiqlash kodi orqali parolsiz bir zumda kirish.
- 📸 **Profil Tahrirlash:** Galereyadan yangi profil rasmi tanlash, ism va telefon ma‘lumotlarini yangilash.
- 💬 **Jonli Chat:** Mashina egasi bilan muloqot va avtomatik javoblar.
- ❤️ **Yoqtirganlar (Favorites):** Mashinalarni saralash va alohida sahifada ko‘rish.
- 🔔 **Bildirishnomalar (Notifications):** Yangi ijaralar va tizim yangiliklari.
- ⚡ **100% Serverless / Standalone:** `index.html` faylini ochish kifoya — hech qanday server yoki o‘rnatish shart emas!

---

## 🚀 Ishga Tushirish

Loyihani ishga tushirish uchun hech qanday o‘rnatish talab etilmaydi:

1. Fayllarni yuklab oling yoki klon qiling:
   ```bash
   git clone https://github.com/sayfullohr/carrent.git
   ```
2. **`index.html`** faylini istalgan brauzerda (Chrome, Safari, Edge, Firefox) oching.
3. Barcha ma'lumotlar brauzerning `localStorage` xotirasida xavfsiz saqlanadi.

## 🛠️ Texnologiyalar

- **Frontend:** HTML5, CSS3 (Modern Flexbox & Grid, CSS Variables), JavaScript (ES6+)
- **Dizayn:** Clean UI, Mobile First, Glassmorphism, Micro-animations
- **Saqlash:** LocalStorage (Offline Client-side Engine)
- **Backend (ixtiyoriy):** Node.js, Express, SQLite, Resend API
